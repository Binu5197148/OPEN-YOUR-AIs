# 🎯 PLAYBOOK: Expansão de Artigos para AdSense

## Objetivo
Transformar artigos curtos (500-800 palavras) em artigos de alta autoridade (1500-2000 palavras) que o Google AdSense considera "high-value".

---

## Fórmula de Artigo High-Value

### 1. HEADLINE PODEROSA (H1)
- Usar números específicos: "7 Ferramentas", "5 Estratégias"
- Prometer resultado concreto
- Incluir palavras-chave de busca

### 2. ESTRUTURA OBRIGATÓTIA

```
## Introdução (150-200 palavras)
- Hook emocional/problemático
- Por que este tema importa AGORA
- O que o leitor vai aprender
- Promessa de resultado

## Contexto/História (200-300 palavras)
- Dados de mercado ou tendência
- Por que isso está em alta
- Impacto no nicho do leitor

## O QUE É / O QUE É DIFERENTE (300-400 palavras)
- Explicação detalhada
- Diferenciação vs alternativas
- Por que importa para o leitor

## TUTORIAL PASSO-A-PASSO (400-500 palavras)
- Passo 1: [ação específica]
- Passo 2: [ação específica]
- Passo 3: [ação específica]
- Screenshots/descrições visuais

## CASOS DE USO REAIS (200-300 palavras)
- Exemplo 1: [situação → resultado]
- Exemplo 2: [situação → resultado]

## MINHA ANÁLISE/OPINIÃO (200-300 palavras)
- O que funciona
- O que NÃO funciona
- Armadilhas a evitar
- Previsão de tendência

## CONCLUSÃO + CTA (100-150 palavras)
- Resumo dos pontos-chave
- Próximos passos recomendados
-call-to-action (inscrever, compartilhar, comentar)
```

## Checklists

### Artigo Pronto para Publicar
- [ ] 1500+ palavras
- [ ] Pelo menos 3 subtítulos (H2)
- [ ] 1 tutorial passo-a-passo
- [ ] 1 exemplo de caso de uso real
- [ ] Opinião pessoal incluída
- [ ] Imagem/cobertura visual mencionada
- [ ] CTA claro no final
- [ ] Data de publicação
- [ ] Nome do autor com bio

### SEO Técnico
- [ ] Meta description única
- [ ] URL amigável (/blog/nome-artigo)
- [ ] Schema Article
- [ ] Open Graph tags
- [ ] Imagem com alt text
- [ ] Internal links para outros artigos
